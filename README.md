# CSC 580 Assignment 1 - GitHub + AI Engineering Practice

This is an AI-assisted portfolio website built as part of CSC 580. The project demonstrates professional
GitHub workflow and responsible use of generative AI in software development. Starting from a portfolio template,
I used an AI assistant to help personalize and enhance the site, including updating content, improving layout,
and ensuring accessibility, while maintaining rigorous code review, testing, and documentation of every change.
The site is published on GitHub Pages and includes detailed records of the planning, implementation, review,
and testing process.
